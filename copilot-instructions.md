# Инструкции для GitHub Copilot (serverApp)

- Используй Node.js (ES6+).
- Для асинхронных операций используй async/await.
- Отступы — 2 пробела.
- Кавычки — одинарные.
- Не используй var, только let и const.
- Для логирования используй встроенный logger.js.
- Не используй jQuery и DOM API.
- Все тесты должны быть на Jest.
- Не добавляй комментарии, если не требуется явно.
- Соблюдай модульную структуру: бизнес-логика — в services, классы — в classes.
- При изменении или написании кода, обновляй или создавай Unit-тесты для него.
